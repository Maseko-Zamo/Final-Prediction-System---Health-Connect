# Final-Prediction-System---Health-Connect

## Overview

HealthConnect is a data science project focused on understanding and predicting patient appointment no-shows using historical healthcare appointment data.

## Objective

The goal is to identify factors associated with missed appointments and develop a machine learning model that predicts whether a patient is likely to attend or miss an appointment.

## Key Features

* Booking lead days
* Patient age
* Previous no-shows
* Distance to clinic
* Waiting time
* Booking-day category
* Distance category
* Reminder received

## Approach

The project included data preparation, exploratory data analysis, feature engineering, model training, testing and evaluation. Different classification models were tested before selecting the final approach.

## Key Findings

The analysis found a high appointment no-show rate, with factors such as **distance, previous no-shows and reminders** providing useful predictive signals.

## Business Value

The solution could help HealthConnect identify patients at higher risk of missing appointments, support targeted reminders and improve clinic resource planning.

## Limitations

The model relies on historical data and may not account for unexpected patient circumstances or changes in appointment behaviour.

## Tools

**Python | Pandas | NumPy | Scikit-learn | Matplotlib | Streamlit| HTML| CSS | Flask**

## Project Outcome

The final model provides a prediction of whether a patient is **likely to attend** or **likely not to show up**, supporting data-driven healthcare decision-making.
